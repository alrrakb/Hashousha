## Task Execution Guidelines for Agent Beta
1. When starting a task, change status to `🟡 In-Progress`.
2. Inspect the task directory: `tasks/TASK-XXX-<slug>/`.
3. Read `SPEC.md` thoroughly before any code change.
4. Fill in `SKILLS_USED.md` (Phase B) mobilizing required skills from `.agents/skills/` and keep real-time logs in `EXECUTION.log` (Phase C).
5. Run automated lint and build verification.
6. Author `POST_MORTEM.md` (Phase D) with ADRs and verification checklist, then update this ledger row to `✅ Completed`.
